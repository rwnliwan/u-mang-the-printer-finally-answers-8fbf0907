One line, in the office printer's own voice, as its comeback to everyone
staring at it:

> I print on both sides. Pity you only ever read one, and it is usually the wrong one.

`main.ts` (Node stdlib only) writes that line exactly — no trailing
newline, UTF-8 — to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set).
